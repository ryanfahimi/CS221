# Exam

The coding portion of the **final**, as submitted: [`1.c`](Final/1.c) through [`4.c`](Final/4.c),
plus [`test.txt`](Final/test.txt) as input data for whichever question needed a file.

Exam material is in Drive under `Exam/`:
[CS221 Drive](https://drive.google.com/drive/folders/1y2qJ_GMT6mwkcMrQ_NudOBzD-ISYlIAE).

Four questions is a good indication of what the course considered its core: with the semester's
material spanning pointers, memory management, strings, structs, bitwise operations, file I/O,
processes and threads, and secure coding, only a handful could be examined by writing code. The
presence of `test.txt` shows at least one question required reading and parsing a file — the same
skill as [Project 3](../Project/3/).

Read these alongside the [projects](../Project/), which cover the same ground with more room, and
the [labs](../Lab/), which have the surviving context.
